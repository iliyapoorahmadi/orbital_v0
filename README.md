# اوربیتال (Orbital Celestial)

وب‌سایت تک‌صفحه‌ای مینیمال، مدرن و راست‌چین (RTL) منطبق بر زبان طراحی Stitch.

## استقرار مستقیم در GitHub Pages (Drag & Drop)
این پروژه ۱۰۰٪ با **HTML5**, **CSS3** و **Vanilla JavaScript** پیاده‌سازی شده و هیچ‌گونه نیاز به نصب Node.js، npm، بیلد یا ترمینال ندارد.

### مراحل استقرار:
1. فایل‌های `index.html` و پوشه `assets/` را دانلود کنید.
2. آن‌ها را مستقیماً داخل مخزن (Repository) گیت‌هاب خود بکشید و رها کنید (Drag and Drop).
3. در تنظیمات مخزن (Settings > Pages)، شاخه `main` و ریشه `/ (root)` را به عنوان سورس انتشار انتخاب کنید.
